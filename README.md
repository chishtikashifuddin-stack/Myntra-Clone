# Myntra Clone

A modern and responsive **Myntra Clone** built to recreate the user experience of one of India's largest fashion and lifestyle e-commerce platforms. This project focuses on frontend development, UI design, and responsive layouts while replicating the appearance and functionality of the original website.

## Overview

The project demonstrates the implementation of an e-commerce interface using modern web development technologies. It includes multiple sections such as navigation, product categories, product cards, promotional banners, and shopping features commonly found on the Myntra platform.

## Features

* Responsive user interface
* Modern homepage design
* Product listing section
* Category-based navigation
* Search functionality
* Shopping bag interface
* Wishlist section
* Promotional banners
* Mobile-friendly design
* Clean and organized code structure

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Installation

Clone the repository:

```bash
git clone https://github.com/chishtikashifuddin-stack/Myntra-Clone.git
```

Open the project folder:

```bash
cd Myntra-Clone
```

Run the project:

```bash
Open index.html in your browser
```
